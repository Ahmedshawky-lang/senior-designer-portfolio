CYBERPUNK SENIOR DESIGNER PORTFOLIO — RESPONSIVE VERSION

Open index.html to start.

Pages:
- index.html — homepage
- designs.html — design portfolio
- branding.html — branding portfolio
- videos.html — video / motion portfolio

Shared files:
- styles.css — complete visual system + responsive tablet/mobile breakpoints
- app.js — counters, reveals, desktop interactions, responsive mobile navigation

Responsive behavior included:
- Desktop: original layout preserved
- Tablet: reorganized hero, 2-column category layout, optimized spacing and typography
- Mobile: single-column layout, full-width CTAs, mobile menu, compact cards, horizontal filters
- Touch devices: desktop hover/parallax behavior is reduced to prevent sticky interactions
- Very small phones and landscape phones have dedicated overrides

Replace thumbnails:
Change the src value on any <img class="project-thumb"> or <img class="portal-thumb">.
The layout will crop images automatically with object-fit: cover.

Edit global colors:
Use the variables at the top of styles.css under :root.
